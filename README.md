# E-Commerce Sales Analysis Using Excel

## Project Overview

This project focuses on analyzing e-commerce sales data using **Microsoft Excel**. The data was cleaned, transformed, analyzed, and visualized to generate meaningful sales insights and create an interactive dashboard.

## Objectives

- Clean and organize e-commerce sales data
- Handle missing values and duplicate records
- Standardize Product IDs and data formats
- Integrate data using XLOOKUP
- Perform sales and inventory calculations
- Perform descriptive statistical analysis
- Create PivotTables and PivotCharts
- Create sales visualizations
- Develop an interactive Excel dashboard
- Generate meaningful business insights

## Data Cleaning & Transformation

- Identified and handled missing values
- Checked and removed duplicate records where applicable
- Standardized Product IDs
- Standardized text formatting
- Removed unnecessary columns
- Removed Sub_Category from the cleaned Product Dimension
- Created Inventory Value and Stock Status
- Validated data relationships
- Applied appropriate number, currency, and date formatting

## Data Analysis

- Used XLOOKUP to combine Customer, Product, Store, and Sales data
- Calculated Total Amount and Unit Price
- Performed descriptive statistics using Excel Analysis ToolPak
- Created PivotTables for Category and Region analysis
- Analyzed monthly sales trends
- Compared sales performance across different dimensions

## Visualizations

- Sales by Category – Column Chart
- Sales by Region – Bar Chart
- Monthly Sales Trend – Line Chart
- PivotCharts for interactive analysis
- KPI cards for key sales metrics

## Dashboard

The interactive Excel dashboard includes:

- Total Sales
- Total Orders
- Average Order Value
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Slicers
- PivotCharts
